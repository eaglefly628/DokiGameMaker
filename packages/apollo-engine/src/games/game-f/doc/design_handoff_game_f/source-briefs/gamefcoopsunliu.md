## 〇、一句话 + 三个支柱

**差异化立身之本：传统自走棋是 1v1 爬梯，我们是「三足鼎立的动态平衡」**——把单机丢失的"真人张力"用三国博弈结构补回来。

| 支柱 | 内容 | 阶段 |
|---|---|---|
| P1 **三方混战** | 战场上同时三支军队互相敌对；**枪打出头鸟**（AI 敌意指向最强方）作为内生难度 | C1 |
| P2 **降将** | 三方混战中敌将阵亡掉「招降」标记，主公拾取收编入席（张辽/关羽典故） | C1.5 |
| P3 **孙刘抗曹合作** | 2 真人（蜀+吴）lockstep 联军 vs AI 魏；同视角同 UI、共享战场、联盟羁绊 | C2 |

> 外交结盟/背刺、一统天下元层：**明确押后**（YAGNI；先用 C1 原型验证"三方打起来好不好玩"再叠）。

## 一、N 阵营架构原则（⚠️ 即时生效，约束当前一切实现）

**「阵营 = N 支队伍；每支的控制者 = {人 | AI} 是数据配置」**。单机=1人+2AI、合作=2人+1AI、对战=2人+1AI摇摆国——**三种拓扑都只是配置，不是代码分叉**。

落到纪律（PE-F 自查，策划审查盯）：
1. **别写死"恰好两队/恰好一个人类"**——队伍位已是掩码（`TEAM_A|B` 加 `TEAM_C` 即三方）；索敌/伤害的"敌方"一律写成 `全队伍掩码 & ~自队`形态的数据，不是硬编码对家。
2. **操作区/HUD 按 owner 参数化**：一份 UI 数据模板，实例化 N 份（owner=p1/p2…）；输入按 owner 路由（card-play 已是先例）。
3. **上阵区 = 按势力的格子范围数据**（deploy zone），不是"下半场=我方"的隐含假设。
4. **lockstep 三纪律继续守**（已在守，成文）：整数 SIM 真相（HexPos）/ 命令式输入 / 表现不进 hash。

**数据映射与缺口**：1-3 纯数据/接线风格约束，零新能力；4 的唯一未验证点 = 战斗浮点跨端一致 → **REQ-F-056 确定性探针**（已入池，见 §五）。

## 二、三方混战（C1，单机先行：玩家蜀 vs AI魏 + AI吴）

### 2.1 战场行为（近乎免费）

- 索敌：蜀 `targetTag=魏|吴`，魏 `=蜀|吴`，吴 `=蜀|魏`（aggro/hitbox 全吃掩码，纯数据）。
- 胜负：三个 Zone present flag；**我方存亡才是回合胜负**，魏吴互灭只改战利品/伤害分布。
- 涌现白送：站位=站队（靠角落让魏吴中路互耗=渔翁得利；谁站中间谁两线作战）。

### 2.2 枪打出头鸟（内生难度，防龟缩的结构支点）

- 开战拍：按三方**战力评分**（Σ存活单位×星级权重，复用 §4.2 权重表）标出「出头鸟」全局 flag；
- AI 方索敌**优先级**偏向出头鸟（实现候选：出头鸟方单位加临时 `THREAT` 位，他方 Perception.targetTag 含 THREAT 优先——具体机制 PE-F 推演，表达不了再提池）；
- 玩家强→被联手扑；玩家苟→魏吴互咬。**难度从博弈长出来，不靠数值硬堆**。

**数据映射与缺口**：战力评分=group-count（REQ-022 done）按队伍×星级计数→加权进全局资源→EventWhen 比大小写 flag——预判纯数据可拼；「索敌读优先级」若 Perception 表达不了按位优先,提池（先重组）。

### 2.3 降将（C1.5，复用已上线的主角拾取）

敌将阵亡 `Mortal.dropTemplate:'recruit_token_<hero>'`（按掉落表几率）→ 主公碰拾（044 两清机制原样）→ 该英雄入备战席（= 造席位 marker，升星合成链自动吃）。席满则不掉/转金币。
**缺口预判**：拾取→「按 token 码造对应英雄席位」= REQ-F-040 playedCodeResource 同形的"据码分发"，词汇已全。

### 2.4 平衡注记（设计责任，先记账）

- 龟缩流解药=出头鸟机制（上）；雪崩软化=关卡曲线+连败金已有；
- **性能**：三方单场单位 ~24-30，aggro N²/overlap 已知债🟠——每方上限先压 8-10，C1 验收时跑性能探针。

## 三、赤壁战场（用户拍板：扩盘 + 梯形 + 长江 + 桥）

> 现状澄清：棋盘几经演化(7×8→12×12→**7×8 真棋盘**,用户钦定批 7efb0cd 回归金铲铲制式)。本节是**三方/合作模式专用战场**，"每个模式/战役一份棋盘数据"。

### 3.1 形状提案（TUNE 起点）

```
        ┌──────────── 魏军区 12 列 × 4 行 ────────────┐     ← 上底窄
        │  曹军大营（AI，可容 12–16 子，"魏国比较多"）   │
        ├─～～～～～～ 长 江（水，1 行，不可走）～～～～～┤
        │      ════桥════              ════桥════      │     ← 两座桥 = 战术咽喉
        ├──────────────────────────────────────────────┤
        │     蜀军区 8 列        │       吴军区 8 列     │     ← 下底宽 16 列 × 4–5 行
        │   （玩家A，左翼）      │    （玩家B，右翼）     │
        └──────────────────────────────────────────────┘
```

- **梯形**：上底 12 / 下底 16 / 高 10（含水 1 行）；缺角格 = 不存在的格子。
- **长江+双桥**：近战必须挤桥（咽喉博弈、堵口站位）；**远程/法术隔江直射**（caster at:'target' 无距离门——史实"隔江箭雨"白送，设计上保留）。桥宽 1–2 格 TUNE。
- 法球/招降标记落点偏中线与桥头 → 双主公竞速有戏。

### 3.2 数据映射与缺口（按"先重组"纪律）

1. **首选重组（零新能力，PE-F 先试）**：水格/缺角格 = **静态占位实体**（HexPos+无队伍 Tag+不可摧毁）——A* 视占位为障碍则天然绕行，桥=不放占位的缝。表现层水纹/桥面=Sprite 数据。
2. **若 A* 占位语义不含静态体**（只认棋子），则提池：`HexBoard` 加 `blockedCells?: (col,row)[]` 或 per-cell 通行掩码——通用地形语义（任何战棋要）。**先试 1，证伪了再提**。
3. 上阵合法区收窄为各自国土（deploy zone 数据,§一.3）。

## 四、孙刘抗曹 · 双人合作（C2，lockstep）

> 参照系=金铲铲官方双人模式（Double Up），三国化升级：**同一张战场并肩**，不是分场打。

### 4.1 模式骨架

| 项 | 规则 | 数据形 |
|---|---|---|
| 阵容 | 玩家A=蜀、玩家B=吴，联军 vs AI 魏（按赤壁战役关卡表：新野→长坂坡→江夏→**赤壁决战**） | 关卡表换一组条目 |
| 经济 | **各管各**（各自 gold/商店/席/等级/连胜）+ **限额赠予**（金/棋子/装备,有冷却防双倍经济） | 资源 id 带 owner 后缀（`gold_p1`…全局 id 注册表扩列）；赠予=命令→改 owner |
| 血量 | **团队共享 player_hp**（输了一起疼，金铲铲双人制） | 现成单例不动 |
| 开战 | **双 ready**：`ready_p1 ∧ ready_p2` | prep 转移条件改 and，一行数据 |
| 战斗 | 两家棋子同场（蜀左吴右），魏军过江/守江 | 三方掩码同 §二 |
| 羁绊 | 默认**各算各**（防平衡爆炸）+ 极少数**联盟羁绊**：跨玩家组合点亮（诸葛亮(蜀)+周瑜(吴)同场→**火烧赤壁**全队增益） | group-count 按跨队伍组合 Tag 计数,纯数据 |
| 主公 | 双主公同场捡战利品（竞速自带乐子；贵重掉落落中线） | 第二份主角数据 |

### 4.2 同视角同 UI（用户拍板「两边 UI 一致」）

- **两端字面渲染同一个世界、同一个朝向**（魏上、蜀左下、吴右下）——"左翼/中缝"对两人是同一处，沟通成本砍半；合作**不做镜像**（镜像是 PvP 的需求）。
- **布阵实时互见 = lockstep 本身**：队友拖子的命令两端同拍模拟,零额外开发——"互相传递占位情况"不是功能,是架构。
- 端间唯一差异 = 本地 owner（我点谁的商店才生效 + 我的操作区高亮）。
- 详细屏幕设计 → **`docs/design/game-f-coop-ui-brief.md`**（已派 Cloud Design）。

### 4.3 联机工程边界（给主程的诚实账）

- 已有底子：2 人 lockstep 卡牌确定性已证（REQ-016/017）；HexPos 整数 SIM；命令式输入；hash 纪律。
- **唯一硬骨头**：战斗浮点（overlap/aggro 距离/投影）跨端逐位一致未验——浏览器全员 IEEE-754,风险比原生跨架构小得多,但**要证不要赌** → **REQ-F-056 确定性探针**（先行,便宜,失败的退路=战斗整数化,代价已知）。
- 网络层（房间/信令/重连）= C2 才做,本文不展开。
