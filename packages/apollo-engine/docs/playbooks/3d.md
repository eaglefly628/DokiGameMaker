## 铁律（3D 全线·每步校）
- **render-only**：所有 3D 组件是表现层——**绝不进 sim/hash、绝不被 Condition 读**（入 determinism NON_DETERMINISTIC·可用随机/时间/三角）。
- **sim 只持 key**：模型/贴图/材质在蓝图里**只写字符串 key**（可哈希回滚），**绝不塞 URL/二进制**。真实字节在资产层。
- **闭集数据**：预设/用途/图案/通道全是闭集枚举（弱 LLM 只能选+填标量·填不了矩阵/插值/自由代码）。
- **代码边界**：`src/renderer/{three-renderer,three-projection}.ts`·`src/renderer/three/**`·`src/games/game-z/**` = **P3D 独占**，别的 session 勿擅改（契约 `docs/workflow/finish/P3D-game-z-handoff.md §0.1`）。
- **UI 不在这**：3D 场里的 HUD/菜单/面板走 **LayoutNode**（读 `docs/design/ui-playbook.md`），**禁**手写 React/DOM。战场/棋盘走 render 组件。
- **反捷径工艺律（owner 2026-07-06 批·TGS 吸收）**：先造型→再材质→再光照→最后特效——**禁**给素坯糊 Glow3D/bloom 冒充质感；**主角面（玩家盯着看的主体）禁纯程序化图元充数**（真做不到在资产台账记 blocker）。视觉里程碑验收/出货用 `docs/playbooks/visual-scorecard.md`（8 维 0-3 分·premium=全维≥2）。

## 做 X → 用哪个基座件

| 做 X | 基座件（组件/能力） | 备注 / 样例 |
|---|---|---|
| 3D 物件（盒/片/球/柱/锥/胶囊/环） | `Mesh3D{shape:box\|plane\|sphere\|cylinder\|cone\|capsule\|torus}` + `Transform3D`（真三维）或 2D `Transform` | 圆润图元单材质·torus 用 `tube`(默认0.35)·`diorama.ts` prim-* 样例 |
| 导入模型（glTF/glb） | `Model3D{modelKey,scale}`（资产 key）+ 骨骼动画 `AnimState3D{clip,speed,loop}` | scale 目前手估→见资产手册「模型导入」缺口·fox 样例 |
| 材质 / PBR | `Material3D{preset\|materialRef,...}`；预设闭集 `assets/pbr-materials`（Filament 金属值） | 预设选一 + 覆盖·`materialRef`=材质数据资产（REQ-Resource ④） |
| 平涂 / 卡通着色（超休闲观感） | `Material3D.shading:'toon'\|'flat'`（+`toonSteps`）+ `outline{width,color}` | `flat`=无光纯亮色(MeshBasic)·`toon`=分段 cel(MeshToon·阶梯明暗)·`outline`=inverted-hull 描边(背面外扩壳·经典卡通黑边)·shading+outline=完整 toon（凸形/道具最佳） |
| 真实贴图（albedo/法线/粗糙/AO/金属/自发光/ORM） | `Material3D.map/normalMap/roughnessMap/aoMap/metalnessMap/emissiveMap/ormMap`(=texture key) + `tiling{repeat,offset}` | 色彩空间按 usage 自动推·法线/ORM 线性·ORM=一图三通道 R=AO/G=Rough/B=Metal（REQ-Resource ①③ + ④补槽） |
| 透明贴图（透明底 PNG·桌面图/树叶/贴花面） | `Material3D.alphaTest`(cutout 阈值·硬边·无排序坑·首选) 或 `Material3D.transparent`(软混合·配 opacity) | 缺省不设=不透明（透明底 PNG 透明区渲黑）。**opt-in**·三渲染器路（MeshStandard）+ 平涂/卡通路都吃（REQ-3D-MAT-ALPHA·game-c 顶视牌桌） |
| 材质 UV 动画（水/岩浆/传送带/序列帧） | `Material3D.uvAnim{scrollX,scrollY}`(滚动) 或 `{fps,cols,rows}`(序列帧) | 渲染器给本材质克隆独立贴图逐帧改 offset/repeat·不影响共享同图的其他物件（休闲缺口·render-only） |
| 地面贴花（阴影/选中/落点/**真图标线**） | `Decal3D{kind:'blob'\|'ring'\|'disc' \| tex, radius\|width/height, rotation, color, opacity, y}` | 平贴无光透明贴地防 z-fight·随实体 XZ 跟随。两路：**程序化 kind**(blob=软接触阴影/ring=选中/disc=splat·零美术)；**自定义贴图 `tex`**(=texture 资产 id·alpha 走贴图通道·下注线/地面 logo/路面标线/桌面图形·`width/height`=非等比长条·`rotation`=地面内 Y 朝向)（REQ-3D-DECAL-TEX·game-z p3-decal-* 样例） |
| 运行时物理施力（弹/射/跳/击退） | 数据 `Impulse3D{trigger,x/y/z,torque?,mode}`(bump trigger) 或 `renderer.applyImpulse(id,...)`(输入胶水甩) | RigidBody3D 初速之外的运行时冲量/设速·nonce 触发防重复（首见=基线不误触发）·弹球/敲击/跳跃通用（休闲缺口·render-only） |
| 物理关节（绳/秋千/吊桥/布娃娃/铰链） | `Joint3D{kind:point\|hinge\|distance\|lock\|cone,bodyB?,pivotA/B,anchor,axis,distance,maxForce}` | 两 RigidBody3D 间或本体↔世界锚建 cannon 约束·两端就绪才建·端点消失自动拆·point=球铰(绳结)/distance=定距(连杆)/hinge=铰链/cone=锥摆(关节)（render-only） |
| 程序化表面细节（零美术文件） | `Material3D.surface{pattern:bumps\|noise\|scratches,tiles,normal,rough,scale}` | 渲染器生成 normal/roughness·确定性·`materialBoard`/场景铺陈样例 |
| 相机（轨道/跟随/正交） | `Camera3D{yaw,pitch,distance,mode:orbit\|follow\|ortho,...}`（数据驱动·永不调相机方法/持矩阵） | 挂一个即进盒庭模式·机位预设见 `diorama.ts` HOME/BOARD_CAM |
| 震屏（打击/得分/失败反馈） | `Camera3D.shake{trigger,amp,freq,decay}` | 撞击时 **bump `trigger`**（任意变化数）→ trauma 注入·衰减自动回正（缺口 B）·超休闲通用打击感 |
| 跟随柔化（软跟随/预读） | `Camera3D.follow{lag,lookAhead}`（配 mode:'follow'） | `lag`=平滑滞后秒·`lookAhead`=朝 target 速度预读秒·帧率无关·收敛省帧（缺口 C）·硬贴设 lag:0 |
| 运镜过渡（平滑切机位/flyby/聚焦） | `Camera3D.tween{trigger,dur,ease}`（设目标机位 + bump trigger） | 世界空间取景 ease（眼位+注视点·含 auto 距离/pivot 解析）·不 bump=硬切（Tier2 缺口·render-only） |
| 光照 | `Light3D{kind:directional\|ambient\|point}` | 暖白主光投软影 + 冷蓝补光·点光有预算 |
| 天空 / 雾 / IBL | `Sky3D{top,bottom,clouds,env,envMap?}`（env=反射强度·envMap=真 HDRI 资产 key）· `Fog3D{color,near,far}` | 天空盒程序化·envMap 走 HDRLoader+PMREM 真反射（缺省/未就绪回退程序化影室）·HDRI ≤2k |
| 画质/性能提帧 | 渲染器选项 `{antialias,dprCap,shadowMapSize}` + 运行时 `setPixelRatioCap()`/`setShadowMapSize()` | GPU 大头=DPR²×后处理 + 每帧阴影。**降 dprCap(retina 提帧最大单点)** / 阴影 1024 / 关 AO(GTAO 最贵) / 用 SMAA 时 antialias:false。game-z「画质档」性能/均衡/画质样例 |
| 后处理 | `Post3D{ao,bloom,grade,tiltShift,aa,vignette,flash}` | AO/辉光/分级/移轴/SMAA 全在·脏值 finite 兜底防黑屏；`vignette{intensity,smoothness,color}`=暗角聚焦·`flash{trigger,color,decay}`=命中全屏闪白(bump trigger 触发·缺口 E·共用分级 pass 零额外开销) |
| 加性辉光 / 粒子 / 世界空间 UI | `Glow3D` · `Vfx3D`（发射器闭集） · `WorldUI3D{text \| node:LayoutNode, offsetY}` | 世界 UI=富 LayoutNode（名牌/血条 ProgressBar/多行面板）锚世界物件屏幕投影·随单位跟随·背相机/出屏自动隐（走 UI 库·UI 铁律）·game-z 狐狸名牌样例 |
| 运动拖尾 / 残影（球滚/滑动/冲刺） | `Trail3D{segments,width,color,minDist,fade,blend}` | 挂移动实体上·记录近 N 帧世界位连成朝相机带·头满尾淡（缺口 D）·位移超 minDist 才采样·`blend:'add'`=发光残影 |
| 世界折线（瞄准线/牵引绳/路径指示/画线） | `Line3D{points,width,color,opacity,dash,gap,closed,blend}` | 给定世界点连成**有宽度的朝相机带线**（THREE 线只有 1px→用带）·`dash>0`=虚线·瞄准弹道游戏算好点填进来·区别 Trail3D 自动记轨迹（render-only） |
| 世界空间广告牌（金币/图标/拾取/emoji/impostor） | `Billboard3D{tex,size,width,height,color,opacity,blend}` | 朝相机贴图 quad（Sprite）·**在场景里参与深度排序·会被遮挡**（区别 WorldUI3D DOM 叠层永在最上）·贴图走 asset key（Tier2 缺口·render-only） |
| UI 贴进 3D 空间（in-world 屏/告示牌/机台/仪表盘） | `Diegetic3D{node:LayoutNode,pxWidth,pxHeight,worldWidth,worldHeight,bg}`（无需 Mesh3D） | LayoutNode→**CSS3DObject 真 DOM 面片**·定位在 Transform3D·按欧拉角朝向·同相机投影(随镜头转/透视)·文字锐利 Chromium 稳。**代价**：DOM 叠层不进 WebGL 深度→不被遮挡/不吃后处理（适合"给人看的"面板）。区别 WorldUI3D 屏幕叠层永朝相机。消费方=contents 展示台（贴图路线 foreignObject 在 Chromium 渲空白故弃用） |
| 程序化位姿动画 / 3D 父子合成 | `Anim3D{channels}` · `Pivot3D{children,center}` | **方法集**：loop=`spin`(自转)/`bob`(正弦)/`osc{wave:sine\|triangle\|saw\|square}`(振荡)/`noise`(有机漂移)；once=`ease{from,to,dur,curve}`(入场)/`spring{to,freq,damping}`(阻尼弹簧·过冲回弹·spawn 弹跳/吸附 juice)。**同 field 叠加**→组合（x/z 双 osc 相位差=环绕·spin+bob=变速自转·ease+spin=弹入并转）。把逐帧手写下沉成数据·game-z prim-* 样例 |
| 挤压拉伸（squash & stretch·弹跳落地） | `Anim3D` channel `field:'scaleX'\|'scaleY'\|'scaleZ'`（+`Transform3D.scaleX/Y/Z`分轴缩放） | 分轴独立缩放（等比 `scale` 之外）·落地 `ease scaleY 1→0.6`+`scaleX 1→1.3` 保体积（缺口 A·超休闲第一 juice） |
| 路径/样条跟随（移动平台/巡逻/dolly/金币弧线） | `Path3D{points,duration,loop,mode,faceDir}` | 沿控制点按壁钟匀速走·linear 折线/smooth Catmull-Rom·loop none/loop/pingpong·faceDir 朝切线（休闲缺口·与 Anim3D 正交·render-only 写 Transform3D） |
| 骰子 / 体素表面 | `Mesh3D.dieFaces[]`(+`dieGlass`) · `Mesh3D.voxelTex{pattern:grass\|stone\|crystal\|plain}` | 程序化 pip/网格纹·纯色 tint 表达不了 |
| 表现物理（滚骰/掉落/翻滚/角色/地形） | `RigidBody3D{shape:box\|sphere\|cylinder\|capsule\|convex\|heightfield,mass,restitution,vx/avx,angularFactor,heights,elementSize,hull}`（cannon-es·**懒加载**·render-only）；**无 Mesh3D 的 RigidBody3D=隐形墙** | 结果写回 Transform3D·**不为联机同步**·cylinder=桶/冰球·**capsule=角色**(Y圆柱+两端半球)·**convex=不规则道具**(给 hull 顶点)·**heightfield=地形**(给 heights 网格·恒静态)·**`angularFactor:[0,1,0]`=锁转轴只平旋永不立边**(硬币/筹码/冰球·`[0,0,0]`=完全锁转·REQ-3D-RB-ANGFACTOR)·`die()`/game-d `throw3d.ts` 样例 |
| 读物理骰点数 / 屏→世界输入 | `upFaceIndex(quat)`（three/dice·读朝上面下标 0..5·面序 [+X,-X,+Y,-Y,+Z,-Z]）· `ThreeRenderer.screenToWorld(x,y,z)`（屏→世界反投影） | 物理落定读确定点数（game-d `throw3d.ts`）· 光标拾取/粒子跟随 |
| 粒子点吸引（跟随鼠标/聚拢） | `Vfx3D.attractor{x,y,z,strength}`（弹簧力+现成 drag=自然加减速） | 每帧写世界点·game-d 尘埃跟随鼠标样例 |
| 逻辑碰撞 / 寻路（sim 侧） | `Collider3D` + `NavMesh` + 能力 `overlap-detect-3d`/`navmesh-bake`/`pathfind`/`collision-resolve-3d` | 升维 2D·进 hash·确定性（只用 +−×÷/sqrt/min/max） |
| 对象拾取（点选/悬停 3D 物件） | `Pickable3D{signal,hover?}` + `ThreeRenderer.pick(x,y)` | raycast 在输入层·命中实体 id → `enqueueAction(signal,{arg:id})`→Signal→sim；样例 game-z beacon/crate |
| 画布随视窗缩放 | `ThreeRenderer.resize(w,h)` + init 自动 `ResizeObserver` | 容器撑满→响应式·紧贴画布→空转（无害） |
| 调试可视化（碰撞体/导航/实体编号） | `ThreeRenderer.setDebugColliders(on)` · `setDebugNav(on)` · `setDebugIndices(on)` | render-only debug 覆盖层（开关即失效脏标·下帧反映）。**编号**=给每个带锚实体（Transform3D/2D Transform）一枚稳定 `#N`+id 徽标（按 id 排序 1-based·`IndexDebug.indexMap` 可复现 #N↔id）·供 owner/开发指名反馈「某物件=效果编号 N」·game-z「效果编号」开关/I 键样例 |
| 资产管线（加/导/vendor 3D 美术） | **resource-manager 技能** + `registerAssetIndex`/`buildMaterialCatalog` | 见资产手册 + `docs/design/3d-asset-pipeline-standard.md` |

## 查不到怎么办
- 3D 缺口 / 新 3D 能力需求 → 写 **`docs/workflow/requests-3d.md`**（P3D 域池·独立于 requests.md）→ 等裁决，**绝不绕基座手写 three/自由 system**。
- 表达不了的 UI → 让主程扩 LayoutNode（`docs/workflow/requests.md`），**不手写 React 逃生**。
