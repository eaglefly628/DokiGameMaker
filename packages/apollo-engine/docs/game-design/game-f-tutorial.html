三 国 征 日

自走棋 × 小丑牌 × 炉石收集 —— 率三国群雄，渡海攻岛，争当岛主
新 手 教 程
⚔️ 武将是「租来的」
每局从零开始买将、人人阵容平等 —— 公平来自操作与运营，不来自氪金抽将。
🃏 小丑牌牌组才是你的「灵魂」
持久收集的小丑牌 + 附魔，定义你的流派身份，带进每一局 —— 这是你真正在养的东西。
①

一图看懂：两个循环

局内攻岛 ⟲ 局外养成，互相喂养

🗾 局内 · 一局攻岛（roguelike）

选好牌组出战 → 备战买将布阵装备 → 自走棋攻打太阁守军、放锦囊、攒贡献度 → 波次推进 → 岛陷落结算。

🏯 局外 · 养成（炉石/Balatro）

攻岛赚战功 + Boss 宝箱掉小丑牌 → 进收藏 → 抽卡/附魔/组牌 → 段位涨（岛更凶）→ 赛季轮换 → 再出战更深。

②

局内 · 一局怎么打

金铲铲式自走棋
▸ 单局流程
🎴
1. 选牌组出战
从收藏组好的小丑牌牌组 + 选势力（魏/蜀/吴），定本局流派。
→
🛡️
2. 备战
花金币买武将上场、布阵；三星合成升星；拖装备到武将；凑势力/职业羁绊。
→
⚔️
3. 攻岛开战
自走棋自动战斗 VS 太阁守军；关键时刻主动放锦囊（火烧/定身/空城…）。
↓
📈
4. 攒贡献度
击杀守军、推进战线 → 累积贡献度（多人局里：贡献最高者当岛主）。
→
🌊
5. 波次推进
W1→W6 六波，越深守军越凶（太阁名将 Boss 招牌登场）；攻岛进度条上涨。
→
🗾
6. 岛陷落 · 结算
攻岛满 = 天守陷落通关 → 赚战功（软币）+ Boss 宝箱掉小丑牌入收藏。
结算产出 → 喂给局外养成 → 下次带更强牌组回来打更深的岛
③

局外 · 养成循环

你的灵魂在这里变强
🎖️
战功 + 掉卡
攻岛按贡献/名次赚战功；Boss 宝箱掉小丑牌进收藏。
→
🎲
抽卡 / 收藏
战功抽卡（概率公示，单抽/十连保底）→ 小丑牌入收藏。
→
✨
附魔 / 组牌
分解多余卡化尘 → 附魔升流派钥匙牌；用收藏自组 5–8 张牌组。
→
🏆
段位 / 赛季
按名次涨段位（高段位的岛守军更凶）；赛季轮换软重置、防强度永固。

核心系统速查

♟️
自走棋战斗
买将/布阵/升星/羁绊，自动开打
🃏
小丑牌牌组
持久收集，定义流派，带进每局
🗡️
装备系统
武器/盔甲/名马/饰品，拖拽穿戴、点击拆解
📜
锦囊（主动牌）
火烧连营/定身/空城计/万箭/妙手/疑兵
🏯
太阁守军
谦信/信长/秀吉/家康…名将 Boss 招牌
📊
贡献度 / 岛主
攒贡献攻岛，多人里贡献最高者当岛主
白·普通绿·优秀 蓝·精良紫·史诗橙·传说（带特效）
装备/小丑牌按品级染色，太阁越深掉得越好。
⑤

三句话上手

  • 武将临时、牌组永久：别心疼这局的武将，专心运营你的小丑牌牌组。
  • 羁绊 + 装备 + 锦囊三件套：凑齐势力/职业羁绊、给核心武将堆装备、卡点放锦囊翻盘。
  • 越打越深：赢一局 → 战功抽卡附魔 → 段位涨 → 打更凶的岛掉更好的橙卡橙装，滚起来。
